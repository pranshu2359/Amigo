#Amigo Landing Page
Amigo is a professional and visually appealing landing page built with HTML, CSS, and JavaScript. Designed to be responsive, fast, and easy to customize, it's perfect for promoting products, services, or startup concepts.

🚀 Features
Responsive Design – Adapts beautifully to all screen sizes

Modern UI – Clean, minimal, and stylish layout

Interactive CTA – Call-to-action button with alert feedback

Semantic HTML – Accessible and SEO-friendly structure

Custom Styling – Easily adjustable color palette and layout
